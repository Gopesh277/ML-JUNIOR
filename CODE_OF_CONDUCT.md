# Code of Conduct

## Our Pledge

We want ML-JUNIOR to be a welcoming, respectful, and constructive open-source project.

We are committed to providing an environment where everyone can participate regardless of experience level, background, or contribution history.

## Expected Behavior

Contributors and community members are expected to:

* Be respectful and professional.
* Be open to constructive feedback.
* Discuss technical disagreements respectfully.
* Help newcomers when possible.
* Focus on improving the project.
* Give credit where credit is due.
* Respect different perspectives and approaches.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or discrimination.
* Personal attacks.
* Trolling or deliberately disruptive behavior.
* Threats or intimidation.
* Publishing someone's private information without permission.
* Sexual harassment or inappropriate conduct.
* Repeatedly disrupting discussions or contributions.
* Any other behavior that would reasonably make the project community unsafe or hostile.

## Project Discussions

Technical disagreements are normal in open-source development.

When disagreements occur, focus on:

1. The problem being solved.
2. Technical evidence.
3. The project's goals.
4. Constructive alternatives.

Disagreement with an idea is not disagreement with a person.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, commits, or other contributions that violate this Code of Conduct.

Serious or repeated violations may result in temporary or permanent removal from project participation.

## Reporting

If you experience or witness unacceptable behavior, please report it privately to the project maintainer through the contact method provided in the GitHub repository.

Please do not create a public issue for sensitive reports.

## Scope

This Code of Conduct applies to project repositories, issues, pull requests, discussions, and other spaces where community members represent or participate in ML-JUNIOR.

Thank you for helping keep ML-JUNIOR a respectful and welcoming project.
